# M1 基座阶段报告

> 项目：大数据安全治理与服务保障平台（软著演示版）V1.0.0　阶段：M1 基座　日期：2026-11-07
> 对应开发方案：阶段二"基础架构与数据模型"（第 11–25 工作日）　报告人：docs-owner

## 一、范围与判据

本阶段交付"能起来、有数据、能鉴权、能看数"的基座：Docker 依赖、27 张表与可重放种子、Express 5 骨架、JWT 认证与安全策略、RBAC 中间件、审计中间件、看板接口、前端工程基座。出口判据（见 [PLAN-MATRIX.md](../PLAN-MATRIX.md)）：

1. `docker compose up -d` 后 MySQL 13306、Redis 16379 可用；`node api/db/init.mjs` 可重建 27 表并重放种子，`node api/db/validate.mjs` 全项 PASS。
2. `GET /api/health` 返回 UP，MySQL/Redis 均 UP。
3. 演示账号可登录，JWT 12 小时、失败锁定生效。
4. 看板接口返回 64 资产、四级分级等聚合数据。
5. 前端基座可启动（路由、Store、Axios、格式化就绪）。
