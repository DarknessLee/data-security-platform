# 计划映射矩阵（PLAN-MATRIX）

> 用途：把开发方案（90 工作日 6 阶段）逐条映射到本 Demo 的 5 个里程碑与能力项，标明落地方式、验收标准与状态。
> 状态口径（手册固定四值）：**已实现**（功能可用且过门禁）/ **部分**（已落地但仍依赖其它模块合入）/ **暂缓**（本期不做、后续可补）/ **不做**（明确排除）。
> 落地程度（辅助列）：完成 / 演示近似 / 暂缓 / 不做；"演示近似"表示流程与数据闭环完整，但底层能力为模拟实现（见 [DECISIONS.md](DECISIONS.md) D-012）。
