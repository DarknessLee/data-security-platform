# 前端开发约定（V1.0）

> 技术栈按开发方案硬性要求：Vue 3 组合式 API + TypeScript + Vite + Element Plus + Pinia + Vue Router 4 + Axios + ECharts。
> 所有页面必须使用真实接口数据，禁止写死演示文案（表头、按钮、菜单除外）。

## 一、目录与归属（写权限隔离）

| 归属 | 路径 | 说明 |
| --- | --- | --- |
| 各模块负责人 | `web/src/views/<module>/*.vue` | 只写自己模块页面 |
| 各模块负责人 | `web/src/api/<module>.ts` | 自己模块的接口封装 |
| 各模块负责人 | `web/e2e/<module>.spec.ts` | 自己模块的 E2E 用例 |
| 公共基座（Lead 维护） | `web/src/api/client.ts`、`web/src/stores/auth.ts`、`web/src/components/*`、`web/src/router/index.ts`、`web/src/layouts/*`、`web/src/styles/*`、`web/src/utils/*` | **禁止修改**；缺能力请发消息给 lead |

页面文件路径由 `web/src/router/index.ts` 固定引用，**文件名必须完全一致**（见各模块任务卡）。

## 二、接口封装

`web/src/api/client.ts` 导出：

```ts
import { http } from '@/api/client';

// GET：返回 { data, meta }
const res = await http.get<AssetRow[]>('/assets', { page: 1, pageSize: 10, keyword: '客户' });
res.data; res.meta?.total;
// POST / PUT / DELETE：返回 { data }
await http.post('/assets', payload);
await http.put(`/assets/${id}`, payload);
await http.del(`/assets/${id}`);
```

- 自动携带 `Authorization: Bearer <token>`；401 自动跳转登录页并提示。
- 非 2xx 统一 `ElMessage.error(message)` 后 reject，页面只需 `try/catch` 做 loading 收尾。
- 下载类接口（CSV 导出）直接 `window.open` 或 `fetch` blob，不走 http 封装。

## 三、页面骨架

每个列表页统一结构（示例）：

```vue
<template>
  <section class="page">
    <PageHeader title="资产台账" subtitle="覆盖 8 个来源系统的数据资产分类分级台账">
      <el-button type="primary" :disabled="!auth.canWrite('asset')" @click="openCreate">登记资产</el-button>
      <el-button @click="exportCsv">导出台账</el-button>
    </PageHeader>

    <el-card shadow="never" class="filter-card">
      <el-form :inline="true" :model="query">
        <el-form-item label="关键词"><el-input v-model="query.keyword" clearable placeholder="资产名称/编号" /></el-form-item>
        <el-form-item label="数据级别">
          <el-select v-model="query.level" clearable placeholder="全部">
            <el-option v-for="l in LEVELS" :key="l" :label="l" :value="l" />
          </el-select>
        </el-form-item>
        <el-form-item>
          <el-button type="primary" @click="reload">查询</el-button>
          <el-button @click="resetQuery">重置</el-button>
        </el-form-item>
      </el-form>
    </el-card>

    <el-card shadow="never">
      <el-table v-loading="loading" :data="rows" stripe>
        <el-table-column prop="asset_code" label="资产编号" width="140" />
        <!-- ... -->
      </el-table>
      <el-pagination
        v-model:current-page="query.page" v-model:page-size="query.pageSize"
        :total="total" layout="total, sizes, prev, pager, next, jumper"
        @current-change="load" @size-change="load" />
    </el-card>
  </section>
</template>

<script setup lang="ts">
import { onMounted, reactive, ref } from 'vue';
import { ElMessage } from 'element-plus';
import PageHeader from '@/components/PageHeader.vue';
import { http } from '@/api/client';
import { useAuthStore } from '@/stores/auth';

const auth = useAuthStore();
const rows = ref<any[]>([]);
const total = ref(0);
const loading = ref(false);
const query = reactive({ page: 1, pageSize: 10, keyword: '', level: '' });

async function load() {
  loading.value = true;
  try {
    const res = await http.get('/assets', { ...query });
    rows.value = res.data as any[];
    total.value = res.meta?.total ?? 0;
  } finally {
    loading.value = false;
  }
}
function reload() { query.page = 1; load(); }
function resetQuery() { Object.assign(query, { page: 1, keyword: '', level: '' }); load(); }
onMounted(load);
</script>
```

## 四、公共组件（Lead 维护，直接用）

| 组件 | 用法 |
| --- | --- |
| `PageHeader.vue` | `props: { title: string; subtitle?: string }`；插槽放操作按钮 |
| `StatCard.vue` | `props: { label: string; value: string \| number; unit?: string; tone?: 'primary'\|'success'\|'warning'\|'danger'; hint?: string; icon?: string }` |
| `ChartBox.vue` | `props: { title?: string; height?: number; option: EChartsOption; loading?: boolean }`，内部自适应容器宽度并自动销毁 |
| `StatusTag.vue` | `props: { value: string; kind?: 'level'\|'result'\|'status'\|'risk' }`，按值自动映射颜色 |
| `EmptyState.vue` | `props: { description?: string }`，无数据占位 |
| `DetailDrawer.vue` | `props: { modelValue: boolean; title: string; width?: string }`，`v-model` 控制，插槽放详情内容 |

工具：`web/src/utils/format.ts` 提供 `fmtNumber(n)`、`fmtMoney`、`fmtDateTime(s)`、`fmtDate(s)`、`fmtPercent(v)`、`fmtSizeGb(v)`。

## 五、权限与状态

- `const auth = useAuthStore()`；`auth.user`、`auth.menus`、`auth.canRead(code)`、`auth.canWrite(code)`。
- 写操作按钮统一 `:disabled="!auth.canWrite('<module>')"`，并在提交前二次确认（`ElMessageBox.confirm`）用于敏感操作（分级调整、共享审批、删除类）。
- 状态颜色映射统一走 `StatusTag`，不在页面里散落 `el-tag` 颜色判断。

## 六、E2E 约定（Playwright，1.55）

- 文件：`web/e2e/<module>.spec.ts`，每个模块 4–8 条用例，覆盖：登录后进入模块页（无 console 错误）、列表有数据、筛选生效、详情/抽屉打开、写操作（有权限账号）成功并出现成功提示、无权限账号看不到写按钮或接口 403。
- 统一使用 `web/e2e/helpers.ts`（Lead 维护）的 `loginAs(page, 'admin')`、`expectNoConsoleError`。
- 选择器优先 `getByRole('button', { name: '...' })`、`getByText('...')`、`data-testid`；避免依赖 Element Plus 内部 class。

## 七、质量门禁

完成标准（每个模块都必须满足）：

1. `cd api; npx tsc --noEmit` 0 错误；
2. 该模块所有接口用真实数据返回 200，含分页与筛选；
3. `cd web; npx vue-tsc --noEmit`（如已配置）与 `npm run build` 通过；
4. 页面在浏览器 1440×900 下无横向滚动条、无 console 报错、ECharts 图表有数据；
5. 写操作留痕：操作后 `audit_log` 新增对应记录（后端自动）。
