# 需求溯源（方案功能点 → 实现位置）

> 用途：证明开发方案 §3.1–§3.6 的每一条功能点都能在本项目 中找到落点（接口 / 页面 / 数据表），供验收与评审逐条核对。
> 口径：接口以 [接口契约.md](接口契约.md) 为准（V1.0 端点清单 + V1.1 响应结构 + V1.2 实现清单）；页面路由以 `web/src/router/index.ts` 为准；数据表以 `api/db/schema.sql` 为准；状态与 [PLAN-MATRIX.md](PLAN-MATRIX.md) 一致（已实现 / 部分 / 暂缓 / 不做）。
> 页面路径前的 `/` 为前端路由（如 `/asset/list` 即 `http://127.0.0.1:5174/asset/list`）；页面文件在 `web/src/views/<module>/`，模块负责人并行开发中。
